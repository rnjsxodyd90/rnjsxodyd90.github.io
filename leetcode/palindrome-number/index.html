9. Palindrome Number

View problem on LeetCode →

Approach

A palindrome reads the same forwards and backwards. Convert the integer to a string, reverse it with slicing ([::-1]), and check whether the two are equal.

O(n) time in the number of digits, O(n) space for the string copy.

Solution

class Solution(object):
    def isPalindrome(self, x):
        """
        :type x: int
        :rtype: bool
        """
        str_x = str(x)
        return str_x == str_x[::-1]

Personal review

My first instinct was to reverse iteration by slicing with [::-1], but integers aren’t sliceable, so I would have had to convert to a string anyway. My first attempt also looked like this:

for i in range(x[::-1]):
    if i == x[i]:
        return true
    return False

Which is broken in a few ways — range(x[::-1]) doesn’t make sense, true should be True, and the return False was nested inside the loop so it would bail after the first iteration. Once I accepted that the cleanest path was to just stringify and compare, the solution collapsed into one line.
