1929. Concatenation of Array

View problem on LeetCode →

Approach

The output array is twice the length of nums. Iterate from 0 to 2n, and for each index i append nums[i % n]. The modulo wraps the index back to 0 once we cross the original length, which naturally produces the concatenation in a single loop.

O(n) time, O(n) space for the output.

Solution

class Solution(object):
    def getConcatenation(self, nums):
        """
        :type nums: List[int]
        :rtype: List[int]
        """
        ans = []
        for i in range(0, 2 * len(nums)):
            ans.append(nums[i % len(nums)])
        return ans

Personal review

I knew that I had to iterate nums, and the length of nums had to be somehow related to that range. I then tried += and it didn’t work because the string was not iterable. Then I just appended and it worked. % allows me to reset the range and start from 0.
